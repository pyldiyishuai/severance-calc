## 二、判断一个词值不值得做

三条标准，全部满足才做：

1. **有明确的计算/查询动作** —— 「离职补偿」有，「劳动法」没有
2. **搜索结果页没有强势的工具站** —— 如果前三名都是律所官网，可以从长尾切
3. **能自然接上广告或线索** —— 法律咨询 CPC 高，招聘类低，但都可以

反例：「劳动合同法全文」——搜索量大，但用户要的是文本，不是计算器，接不上。

## 三、冷启动

工具站的冷启动不靠 SEO（新站沙盒期 3-6 个月），靠这三条：

### 1. 先让搜索结果里有你

新站最快被收录的方式不是提交 sitemap，而是**有外链指向你**：
- 知乎回答里带链接（注意不要被判营销）
- 相关论坛/贴吧的实用回复
- GitHub 上开源这个项目，README 里放线上地址

### 2. 蹭时间点

离职补偿的搜索有明显的**周期性峰值**：
- 春节后（2-3 月）：年终奖到手，跳槽高峰
- 年中（6-7 月）：校招入职、试用期到期
- 年底（11-12 月）：裁员季、绩效不达标被优化

在这些时间点前 2 周准备内容，效果差 3 倍。

### 3. 把工具做得比竞品好一点点

现有竞品的通病：
- 只算 N，不算 N+1 和 2N
- 不考虑三倍社平封顶
- 不解释钱怎么来的
- 满屏广告

**把这四点做好，就够了。** 这个赛道的竞争不在技术，在「愿不愿意把话说清楚」。

## 五、文案注意

这个领域有**法律风险**，三件事不能做：

1. **不能说「保证能拿到」** —— 仲裁有不确定性
2. **不能替用户做决定** —— 不说「你应该去仲裁」，说「你可以主张 X」
3. **不能省略免责声明** —— 页脚那句「不构成法律意见」必须留着

反过来，**该说的必须说清楚**：
- 2N 和 N 不能同时主张
- 仲裁时效 1 年
- 被迫辞职的解除理由必须写对

含糊其辞反而更容易引发投诉。
